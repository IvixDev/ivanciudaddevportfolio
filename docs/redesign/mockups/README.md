# Mockups del rediseño

Fuente HTML de las 12 pantallas del lienzo de diseño (https://claude.ai/artifact/VfQowbRGuRWJFuPpWpAqip).
Son prototipos con estilos en línea y un pequeño runtime (`{{accent}}` = `#A78BFA`, `{{brand}}` = `#22D3EE`);
**no se copian tal cual**: se traducen a componentes Astro con Tailwind y tokens del design system.
Las rutas `/_blob/<id>` son las imágenes de `src/assets` (retrato, proyectos, Japón, dados, LEGO, traje).
